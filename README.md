# 🎬 QuickTube - YouTube Video Downloader  

QuickTube is a **minimalist yet powerful YouTube video downloader** that allows users to easily download videos and playlists. The platform is designed with **efficiency and user-friendliness in mind**, supporting high-speed downloads with a clean interface.  

![QuickTube Banner](../Quicktube.me/images/home_download.jpg) <!-- Replace with actual image -->  

---

## 🚀 Features  

✅ **Download Single Videos** – Save individual YouTube videos instantly  
✅ **Download Playlists** – Fetch entire playlists with one click  
✅ **Multiple Resolutions** – Supports downloading in different quality settings  
✅ **Minimalist Design** – Clean, simple interface with fast navigation  
✅ **Backend Powered by Flask** – Handles video processing efficiently  

---

## 🔧 Tech Stack  

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Flask (Python)  
- **Database:** SQLite (optional, for storing video history)  
- **Video Downloading:** `yt_dlp` library

## 📂 Installation & Setup  

### 1️⃣ Clone the repository  
```bash
git clone https://github.com/Meargteame/Quicktube.me.git
cd Quicktube.me
```
### 2️⃣ Set up a virtual environment (recommended)
```
pip install -r requirements.txt
```
### 3️⃣ Install dependencies
```
pip install -r requirements.txt
```
### 4️⃣ Run the Flask server
```
python app.py
```
### 5️⃣ Open the app in your browser
```
Go to: http://127.0.0.1:5000/

```
